## 3. Recommended Technical Stack for the Personal Site

| Layer | Choice | Why It Wins |
|---|---|---|
| **Framework** | **Vite 6 + React 19 + TypeScript** *(or Next.js 15 App Router static export)* | Instant `<100ms` route transitions, zero cold-start latency on Vercel, static reliability. |
| **3D & Shaders** | **Three.js / React Three Fiber (`@react-three/fiber`) + Custom GLSL** | Powers the Hero Kyber-Copper Sigil, the exploded 2-Layer KiCad PCB viewer, and Resonate's orb at locked 60fps with mobile fallback. |
| **Motion** | **GSAP + Lenis Smooth Scroll + Framer Motion** | Strictly partitioned (Lenis/GSAP for scroll scrubbers; Framer Motion for UI state/drawers — zero transform conflicts). |
| **Styling & Typography** | **Tailwind CSS v4 + Custom Design Tokens** (`--void #060911`, `--kyber #67E8F9`, `--copper #E8B44C`, `--emerald #34D399`) | Space Grotesk / Instrument Sans display + IBM Plex / JetBrains Mono telemetry. |
| **Quality Gates** | **Automated Build Ledger (`verify-links.mjs` + Lighthouse CI)** | Verifies every outbound URL is `200 OK`, enforces `prefers-reduced-motion`, WCAG AA contrast, and `<200KB` initial JS gzip budget. |
